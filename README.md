# bis
Not one game engine, but the same, again.

This is effectively a monorepo for a custom framework suitable for game development, and many related engines built from said framework.

- [ ] `bartender` Point-and-click adventure.
- [ ] `weakforce` A Classic Fallout clone.
- [ ] `orderstone` A Minecraft clone? The idea is that multiple distinct "chunksets" can exist, which can act as physics objects independent of world terrain. So you could build an airship, and continue to build on it as it is moving.
- [ ] `arcflash` Kodu Game Lab/Project Spark clone.
- [ ] `biscuit` A more general-purpose engine.

Shared code and resources:
- `saddlepoint` Rendering engine.
- `tailmaw` Mathematical functions useful for rendering and physics, some file format support, and some resources like the texture for the missing texture.
